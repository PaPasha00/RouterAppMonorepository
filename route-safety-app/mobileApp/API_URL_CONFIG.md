# Автоматическое определение URL API

Приложение автоматически определяет, какой URL использовать для API запросов.

## Как это работает:

### Приоритет определения URL:

1. **Явная настройка** (высший приоритет):
   - Переменная окружения `EXPO_PUBLIC_API_BASE_URL` в `.env` файле
   - Или настройка в `app.config.js` → `extra.EXPO_PUBLIC_API_BASE_URL`

2. **Автоматическое определение** (если явная настройка не указана):
   - **Веб** (`Platform.OS === 'web'`): `http://localhost:3001`
   - **iOS симулятор** (localhost в debuggerHost): `http://localhost:3001`
   - **Android эмулятор** (localhost в debuggerHost): `http://10.0.2.2:3001`
   - **Реальное устройство** (iOS/Android): `http://46.188.41.57:3011`

## Примеры использования:

### Для локальной разработки (веб/симулятор):

Ничего не нужно делать! Приложение автоматически использует `localhost:3001`.

### Для реального устройства:

Ничего не нужно делать! Приложение автоматически использует production сервер `http://46.188.41.57:3011`.

### Для переопределения URL:

Создайте файл `.env` в папке `mobileApp`:

```bash
# Для локального сервера на другом порту
EXPO_PUBLIC_API_BASE_URL=http://localhost:3002

# Для тестового сервера
EXPO_PUBLIC_API_BASE_URL=http://test.example.com:3011

# Для production (если нужно переопределить)
EXPO_PUBLIC_API_BASE_URL=http://46.188.41.57:3011
```

## Логирование:

При запуске приложения в консоли вы увидите:
```
[API CONFIG] Веб-окружение, используем localhost: http://localhost:3001
[API CONFIG] iOS симулятор, используем localhost: http://localhost:3001
[API CONFIG] Реальное iOS устройство, используем production: http://46.188.41.57:3011
[API CONFIG] Определен базовый URL: http://46.188.41.57:3011
```

## Технические детали:

- URL определяется один раз при первом использовании и кэшируется
- Определение основано на:
  - `Platform.OS` (web/ios/android)
  - `Constants.expoConfig.debuggerHost` (для определения симулятора/реального устройства)
  - `Constants.executionEnvironment` (для Expo Go)

## Отладка:

Если URL определяется неправильно, проверьте логи в консоли. Они покажут:
- Какой URL был выбран
- На каком основании был сделан выбор
- Все доступные источники конфигурации
