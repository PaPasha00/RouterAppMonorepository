# Как проверить, что Web Search работает

## 1. Проверка при запуске сервера

При запуске сервера вы должны увидеть в логах:

```
✅ TAVILY_API_KEY загружен, web search доступен
```

или

```
🔑 Проверка переменных окружения:
TAVILY_API_KEY: настроен (tvly-dev-DytVjC3...)
```

Если видите:
```
⚠️ TAVILY_API_KEY не настроен. Web search будет недоступен.
```
→ Ключ не загружен, проверьте `.env` файл и перезапустите сервер.

## 2. Проверка при анализе маршрута

Когда вы запускаете анализ маршрута, в логах сервера должны появиться следующие сообщения:

### Если web search работает:

```
🔍 Поиск информации о маршруте в интернете...
  🔎 Поиск: "река Москва Московская область координаты 55.7558 37.6173"
  ✅ Найден ответ (450 символов)
  ✅ Найдено 2 результатов
  🔎 Поиск: "сплав по реке Московская область пороги препятствия"
  ✅ Найден ответ (320 символов)
  ✅ Найдено 2 результатов
  📊 Всего собрано информации: 1250 символов из 4 источников
✅ Найдена информация из интернета (длина: 1250 символов)
```

### Если web search не работает:

```
🔍 Поиск информации о маршруте в интернете...
ℹ️ Web search пропущен: TAVILY_API_KEY не настроен
ℹ️ Информация из интернета не найдена или web search недоступен
```

## 3. Что искать в логах

### Успешная работа:
- ✅ `TAVILY_API_KEY загружен, web search доступен` - при запуске
- 🔍 `Поиск информации о маршруте в интернете...` - начало поиска
- 🔎 `Поиск: "..."` - каждый поисковый запрос
- ✅ `Найден ответ (... символов)` - успешный ответ от API
- ✅ `Найдено X результатов` - количество найденных результатов
- 📊 `Всего собрано информации: ... символов` - итоговая статистика
- ✅ `Найдена информация из интернета (длина: ... символов)` - финальное подтверждение

### Проблемы:
- ⚠️ `TAVILY_API_KEY не настроен` - ключ не найден
- ⚠️ `Ошибка поиска для запроса` - ошибка API запроса
- ❌ `Ошибка web search` - критическая ошибка
- ℹ️ `Информация не найдена` - поиск не дал результатов

## 4. Проверка в ответе AI

Если web search работает, AI будет использовать найденную информацию в своих рекомендациях. Вы можете заметить:

1. **Более конкретные рекомендации** - упоминание конкретных рек, троп, препятствий
2. **Ссылки на реальные места** - названия рек, перевалов, населенных пунктов
3. **Актуальная информация** - данные о состоянии дорог, троп, порогов
4. **Отчеты туристов** - упоминание отчетов и описаний маршрутов

## 5. Тестирование вручную

Можно протестировать web search напрямую через API:

```bash
curl -X POST https://api.tavily.com/search \
  -H "Content-Type: application/json" \
  -d '{
    "api_key": "tvly-your-key-here",
    "query": "сплав по реке Москва пороги",
    "search_depth": "basic",
    "include_answer": true,
    "max_results": 3
  }'
```

Если получаете ответ с данными - API работает.

## 6. Типичные проблемы

### Ключ не загружается
- Проверьте, что файл `.env` находится в папке `be/`
- Убедитесь, что ключ записан без кавычек: `TAVILY_API_KEY=tvly-...`
- Перезапустите сервер после изменения `.env`

### Поиск не находит информацию
- Это нормально для редких/неизвестных маршрутов
- Попробуйте маршрут в популярном месте (например, Москва, Сочи)
- Проверьте, что запросы формируются правильно (смотрите логи `🔎 Поиск:`)

### Ошибки API
- Проверьте лимиты бесплатного tier (1000 запросов/месяц)
- Убедитесь, что ключ активен
- Проверьте интернет-соединение
