# Проверка Tavily

Ключ в `be/.env`:

```bash
TAVILY_API_KEY=tvly-...
```

Перезапуск `npm run dev`, затем анализ любого маршрута.

В логах норма:

- `Поиск информации о маршруте`
- `Найдена информация из интернета`

Без ключа:

- `TAVILY_API_KEY не настроен`
- `Web search пропущен`

Ключ без кавычек в `.env`. На бесплатном tier ~1000 запросов/мес.
