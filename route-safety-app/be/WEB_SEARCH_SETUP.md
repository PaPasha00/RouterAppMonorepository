# Web search (Tavily) для анализа

Перед запросом к OpenRouter бэкенд гоняет Tavily: отчёты о реке/тропе/дороге попадают в промпт. Без ключа анализ всё равно идёт, просто без веб-контекста.

## Настройка

1. Ключ на https://tavily.com
2. В `be/.env`:

```bash
TAVILY_API_KEY=tvly-...
```

3. `npm run dev` в `be/`

В логах при анализе: строки про поиск; если ключа нет — `TAVILY_API_KEY не настроен`.

## Лимиты

Бесплатный tier ~1000 запросов/месяц, `search_depth: basic`. На проде при росте нагрузки — платный план.

Другой провайдер — правки в `be/src/services/webSearchService.ts`.
