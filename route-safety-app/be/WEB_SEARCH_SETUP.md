# Настройка Web Search для анализа маршрутов

## Описание

Система использует веб-поиск для получения актуальной информации о маршрутах, реках, дорогах и местности. Это позволяет AI давать более точные рекомендации на основе реальных данных из интернета.

## Как это работает

1. При анализе маршрута система автоматически ищет информацию в интернете:

   - Для **водных маршрутов**: информация о реке, порогах, препятствиях, отчеты о сплавах
   - Для **пеших маршрутов**: информация о тропах, сложности, отчеты о походах
   - Для **автомобильных маршрутов**: информация о дорогах, состоянии покрытия, проезжаемости

2. Найденная информация добавляется в промпт для AI, который использует её для:
   - Более точной оценки сложности маршрута
   - Конкретных рекомендаций о препятствиях и особенностях
   - Актуальной информации о состоянии троп/дорог/рек

## Настройка Tavily API

### Шаг 1: Получение API ключа

1. Зарегистрируйтесь на [Tavily.com](https://tavily.com)
2. Перейдите в раздел API Keys
3. Создайте новый API ключ
4. Скопируйте ключ (начинается с `tvly-`)

### Шаг 2: Добавление ключа в .env

Добавьте в файл `be/.env`:

```bash
TAVILY_API_KEY=tvly-your-api-key-here
```

### Шаг 3: Перезапуск сервера

После добавления ключа перезапустите сервер:

```bash
cd be
npm run dev
```

## Проверка работы

После настройки при анализе маршрута в логах вы увидите:

```
🔍 Поиск информации о маршруте в интернете...
✅ Найдена информация из интернета (длина: 1234 символов)
```

Если ключ не настроен:

```
ℹ️ Web search пропущен: TAVILY_API_KEY не настроен
ℹ️ Информация из интернета не найдена или web search недоступен
```

## Бесплатный tier

Tavily предоставляет бесплатный tier с ограничениями:

- До 1000 запросов в месяц
- Базовый поиск (search_depth: 'basic')

Для production использования может потребоваться платный план.

## Альтернативные сервисы

Если Tavily не подходит, можно использовать другие сервисы:

1. **Serper API** - Google Search API
2. **Google Custom Search API** - требует настройки Custom Search Engine
3. **Bing Search API** - Microsoft Bing Search

Для замены сервиса нужно обновить `be/src/services/webSearchService.ts`.

## Что ищется

### Для водных маршрутов:

- Название реки по координатам
- Пороги и препятствия на маршруте
- Отчеты о сплавах по этой реке
- Особенности течения и навигации

### Для пеших маршрутов:

- Описание троп и маршрутов
- Отчеты о походах
- Сложность и препятствия
- Особенности местности

### Для автомобильных маршрутов:

- Состояние дорог
- Проезжаемость
- Заправки и сервисы
- Особенности маршрута

## Логирование

Вся информация о поиске логируется в консоль:

- Успешные запросы
- Ошибки поиска
- Количество найденной информации

Это помогает отлаживать и оптимизировать поисковые запросы.
