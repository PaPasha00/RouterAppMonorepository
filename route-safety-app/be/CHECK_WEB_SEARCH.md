# Как проверить работу Web Search

## 1. Проверка в логах сервера

После запуска анализа маршрута проверьте логи сервера (где запущен `npm run dev`).

### Успешная работа Web Search:

```
🔍 Поиск информации о маршруте в интернете...
  🔎 Поиск: "пеший маршрут Москва Московская область тропа отчет"
  ✅ Найден ответ (450 символов)
  ✅ Найдено 2 результатов
  🔎 Поиск: "поход Московская область маршрут сложность"
  ✅ Найден ответ (320 символов)
  📊 Всего собрано информации: 1250 символов из 4 источников
✅ Найдена информация из интернета (длина: 1250 символов)
```

### Если Web Search не работает:

```
🔍 Поиск информации о маршруте в интернете...
ℹ️ Web search пропущен: TAVILY_API_KEY не настроен
ℹ️ Информация из интернета не найдена или web search недоступен
```

## 2. Проверка при запуске сервера

При запуске сервера должно быть:

```
✅ TAVILY_API_KEY загружен, web search доступен
```

или

```
🔑 Проверка переменных окружения:
TAVILY_API_KEY: настроен (tvly-dev-DytVjC3...)
```

## 3. Проверка URL запросов

### Для локальной разработки:

В логах мобильного приложения должно быть:

```
[API CONFIG] Режим разработки (__DEV__), используем localhost: http://localhost:3001
[API CONFIG] Определен базовый URL: http://localhost:3001
[API] Отправка запроса: { url: 'http://localhost:3001/api/analyze-route', ... }
```

### Если видите production URL:

```
[API CONFIG] Определен базовый URL: http://46.188.41.57:3011
```

→ Это означает, что приложение работает в production режиме или есть явная настройка URL.

## 4. Быстрая проверка

1. **Запустите анализ маршрута** в мобильном приложении
2. **Смотрите логи сервера** (терминал где запущен `npm run dev`)
3. **Ищите строки:**
   - `🔍 Поиск информации о маршруте в интернете...`
   - `🔎 Поиск: "..."` - каждый поисковый запрос
   - `✅ Найден ответ` - успешный ответ
   - `✅ Найдена информация из интернета` - финальное подтверждение

## 5. Проверка через curl

Можно протестировать web search напрямую:

```bash
curl -X POST https://api.tavily.com/search \
  -H "Content-Type: application/json" \
  -d '{
    "api_key": "tvly-your-key-here",
    "query": "пеший маршрут Москва",
    "search_depth": "basic",
    "include_answer": true,
    "max_results": 3
  }'
```

## 6. Что делать если не работает

1. **Проверьте ключ в .env:**
   ```bash
   cd be
   cat .env | grep TAVILY
   ```

2. **Перезапустите сервер:**
   ```bash
   cd be
   npm run dev
   ```

3. **Проверьте логи при запуске:**
   - Должно быть: `✅ TAVILY_API_KEY загружен`

4. **Проверьте логи при анализе:**
   - Должно быть: `🔍 Поиск информации...`
